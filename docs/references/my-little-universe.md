# My Little Universe — Reference Analysis

**Developer:** SayGames
**Release:** 2021
**Downloads:** 30M+
**Revenue:** ~$10M (IAP only, source: AppMagic)
**Genre:** Hybrid-casual world-building / survival-craft
**Platforms:** iOS, Android, PC (Steam), Console

## Why It's Relevant to Farhaven

MLU shares the same core DNA: hex-tile world, gather → craft → expand → explore loop. It's the closest comparable on mobile with proven commercial success.

## Core Gameplay Loop

**Collect → Upgrade → Expand**

- Players create their planet tile by tile
- Resources: wood, stone, azurite, amethyst, etc.
- Tiles are unlocked by spending resources — each tile is a resource decision
- Refineries turn raw resources into processed ones (logs → planks)
- Tool/weapon upgrades gate progression (better tools = faster gathering + access to new resources)
- Combat exists but feels like an afterthought (stickman vs enemies)
- Clear quest/task system guides players — always a next objective
- Daily activities drive retention (farm, kill, refine, open tiles, exchange)

## Controls & UX

- Auto-gather: walk near resource → automatic collection (no tap required)
- Simple movement (joystick)
- Straightforward — signs point to important areas
- Accessible to all player types immediately

## Visual Style

- Low-poly, stylized, hyper-casual aesthetic
- Stickman protagonist
- Colorful, cheerful palette
- Isometric 3D perspective
- Clean, readable tiles with clear resource identity
- Floating "+N" text on gather
- Minimal HUD

## Monetization (What We're Avoiding)

- **Hybrid-casual model:** Ads + IAP
- "SPECIAL DEAL" popups with premium currency bundles
- Multiple currencies (gems + coins + resources)
- Ad-boosted rewards (watch ad → 2x daily reward)
- Skin modifiers (mobile version — skins have stat buffs)
- **Farhaven's approach:** $2.99 one-time unlock, zero IAP, zero ads, zero fake currencies

## Progression Systems

1. **Resource tier progression** — new resources increase complexity over time
2. **Tool upgrades** — gate access to harder resources
3. **Tile expansion** — each tile costs resources, is a meaningful choice
4. **Planet completion** — unlock rocket → explore new planets (long-term goal)
5. **Equipment** — armor (helmet, chestplate), pet, horse (late game)
6. **Quest system** — short-term + long-term goals, daily activities

## What Farhaven Borrows

- Hex-tile world with progressive reveal
- Gather/craft/build core loop
- Low-poly visual style (though different aesthetic)
- Tool-gated resource progression
- Floating feedback text on gather
- Portrait mode, mobile-first

## Where Farhaven Diverges

| Aspect | MLU | Farhaven |
|--------|-----|----------|
| Tension | Zero — no survival pressure | Day/night cycle, fauna threats, HP/hunger/thirst |
| Inventory | Global counters | Slot-based with management |
| Monetization | Ads + IAP (predatory) | $2.99 premium, zero IAP |
| Controls | Auto-gather on proximity | Tap-to-gather (one tap more) |
| Art style | Cheerful cartoon | Tactical Brutalism (dark, sci-fi) |
| Difficulty | Casual-idle, no fail state | Survival — death/respawn, resource loss |
| Combat | Afterthought (auto-ish) | Intentional — tap adjacent, weapon tiers, cooldown |
| Save | Cloud + multi-slot | Local JSON, single slot (MVP) |

## Key Takeaway

MLU proves the hex-tile gather/craft/expand loop works at massive scale on mobile. Farhaven layers survival pressure on top of the same proven foundation — the question is whether the darker aesthetic and higher difficulty still attract the mobile audience.
